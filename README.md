# TechBox — учебный магазин техники

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

TechBox — учебный многостраничный сайт интернет-магазина техники и гаджетов: главная страница, каталог с фильтрами, отдельная страница с таблицей характеристик для каждого товара, страница заявки и контакты. Проект написан на чистых HTML и CSS без фреймворков; JavaScript используется только для модального окна и проверки формы.

## Контрольная работа №1

## Обязательные страницы

| Страница | Содержание |
| --- | --- |
| `index.html` | hero-блок, преимущества, популярные товары, модальное окно заявки |
| `catalog.html` | сетка карточек товаров, блок фильтров (статическая разметка), хлебные крошки |
| `product.html`, `product-2.html` … `product-6.html` | по странице на каждый товар: изображение, описание, цена, кнопка заявки, таблица характеристик |
| `order.html` | форма заявки с проверкой полей |
| `contacts.html` | контактная информация и ссылка на форму заявки |

На каждой странице есть уникальные `title` и `meta description`, общая навигация и подключённый `css/style.css`.

## Реализованные элементы

- единая навигация на всех страницах и якорные ссылки (`#advantages`, `#popular`, `#contacts`);
- карточки товаров с изображением, описанием, ценой и ссылкой «Подробнее»;
- таблица характеристик (`caption`, `thead`, `tbody`, `th`, `td`);
- форма заявки: имя, e-mail, телефон, товар, тема, комментарий, согласие;
- модальное окно на элементе `dialog` с той же формой;
- базовая HTML- и JS-валидация, подсветка ошибочных полей через `aria-invalid`;
- сообщение об успешной отправке.

## CSS-архитектура

- CSS-переменные в `:root` для цветов, отступов, скруглений и слоёв (`z-index`);
- состояния `:hover`, `:focus-visible`, `:disabled` для ссылок, кнопок, карточек и полей;
- структурированный файл `css/style.css`, разделённый на смысловые блоки.

## Использование Flexbox и Grid

- Flexbox: основное меню, внутренняя структура карточек, группы кнопок;
- CSS Grid: сетка карточек (`products-grid`), страница каталога «фильтры + товары» (`catalog-layout`), страница товара «изображение + информация» (`product-detail`).

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `product-detail` — страница товара;
- `product-table` — таблица характеристик;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `to-top` — кнопка «Наверх»;
- `site-footer` — подвал сайта.

## Позиционирование

- `position: relative` — карточка товара (контейнер для бейджа);
- `position: absolute` — бейджи «Хит», «Новинка», «Скидка» в карточках;
- `position: sticky` — блок фильтров в каталоге остаётся на экране при прокрутке;
- `position: fixed` — кнопка «Наверх» в правом нижнем углу;
- `z-index` — бейджи, фильтры и кнопка «Наверх» вынесены в переменные слоёв.

## Самостоятельные доработки

- собственная концепция магазина TechBox: название, логотип-фавикон, палитра на CSS-переменных (индиго), тематические товары и иллюстрации;
- отдельная страница для каждого из шести товаров, «Подробнее» ведёт на нужную;
- расширенный каталог из шести товаров с категориями;
- бейджи «Хит», «Новинка», «Скидка», старая цена и красная рамка у товара со скидкой (модификатор `product-card--discount`);
- собственные SVG-иллюстрации товаров и логотип;
- страница товара с макетом «изображение + информация» на Grid;
- предзаполнение страницы заявки выбранным товаром через адрес `order.html?product=...`;
- подсветка активного пункта меню (`site-nav__link--active`, `aria-current="page"`);
- хлебные крошки на внутренних страницах;
- кнопка «Наверх» и sticky-фильтры.
